# موقع خمسة ديجيتال 🛍️

موقع متجر متكامل — واجهة عصرية + قائمة بريدية بترحيب تلقائي + لوحة مالك لإرسال الإيصالات والملفات.
كل الخدمات المستخدمة **مجانية 100%**.

## المكونات
| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة الرئيسية (المنتجات + التسجيل بالإيميل) |
| `admin.html` | لوحة المالك — تفتحها من `موقعك/admin` |
| `api/subscribe.js` | يحفظ الإيميل في قاعدة البيانات ويرسل الترحيب |
| `api/subscribers.js` | يعرض المسجلين (للمالك فقط) |
| `api/send-email.js` | يرسل إيميلاً (إيصال/ملف/إعلان) لواحد أو للجميع |
| `api/admin-login.js` | دخول المالك بكلمة السر |
| `supabase-setup.sql` | كود إنشاء جدول المسجلين — يُشغَّل مرة واحدة |

## خطوات التشغيل (30 دقيقة تقريباً)

### 1) حساب GitHub ورفع الملفات
1. سجّل في github.com بإيميل المتجر الجديد.
2. أنشئ مستودعاً جديداً (New repository) باسم `khamsa-site` — عام (Public).
3. اضغط «uploading an existing file» واسحب **كل محتويات هذا المجلد** دفعة واحدة → Commit.

### 2) قاعدة البيانات — Supabase (مجاني)
1. سجّل في supabase.com بنفس حساب GitHub → New project (اختر أي منطقة قريبة، واحفظ كلمة سر القاعدة).
2. من القائمة: SQL Editor → New query → الصق محتوى `supabase-setup.sql` → Run.
3. من Settings → API انسخ: **Project URL** و **service_role key** (السري — لا تشاركه أبداً).

### 3) الإيميلات — Brevo (مجاني: 300 إيميل/يوم)
1. سجّل في brevo.com بإيميل المتجر.
2. Senders & IP → Senders → Add a sender → أضف إيميل المتجر وفعّله من رسالة التأكيد.
3. من أعلى اليمين: SMTP & API → API Keys → Generate a new API key → انسخه.

### 4) النشر — Vercel (مجاني)
1. سجّل في vercel.com بحساب GitHub → Add New → Project → اختر `khamsa-site` → Deploy.
2. بعد النشر: Settings → Environment Variables وأضف:

| الاسم | القيمة |
|---|---|
| `SUPABASE_URL` | رابط مشروع Supabase |
| `SUPABASE_SERVICE_KEY` | مفتاح service_role |
| `BREVO_API_KEY` | مفتاح Brevo |
| `SENDER_EMAIL` | إيميل المتجر (المفعّل في Brevo) |
| `SENDER_NAME` | خمسة ديجيتال |
| `ADMIN_PASSWORD` | كلمة سر قوية للوحة المالك — اخترها بنفسك |

3. Deployments → أعد النشر (Redeploy) حتى تُفعَّل المتغيرات.
4. رابط موقعك: `khamsa-site.vercel.app` (تقدر تغيره من Settings → Domains).

### 5) جرّب
- افتح الموقع → سجّل إيميلك → المفروض توصلك رسالة الترحيب.
- افتح `موقعك/admin` → ادخل بكلمة السر → تشوف الإيميل المسجل، وجرب إرسال رسالة.

### 6) اربط كل شيء
- حط رابط الموقع في **وصلاتي** وفي **بايو تيك توك**.
- لتعديل المنتجات والأسعار: عدّل قائمة `PRODUCTS` أعلى `index.html` (ورقم الواتساب في `WHATSAPP`).

## ملاحظات مهمة
- **لا ترفع مفاتيحك السرية للموقع أبداً** — مكانها الوحيد Environment Variables في Vercel.
- حد Brevo المجاني 300 إيميل/يوم — كافٍ جداً للبداية.
- لإرسال ملف مع الإيصال: ارفعه على Google Drive → مشاركة «أي شخص لديه الرابط» → ضع الرابط في خانة المرفق.
